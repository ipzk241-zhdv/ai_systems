# Покупки по відділах

Локальна Qwen розподіляє список покупок по відділах магазину. Результат можна використовувати як чекліст.

## Запуск

Потрібні Python 3.10+ і [Ollama](https://ollama.com/download). Після запуску Ollama відкрий термінал у теці `lab4/app`.

```powershell
ollama pull qwen3:4b-instruct-2507-q8_0
ollama create lab4-q8 -f q8.Modelfile
python server.py
```

## Налаштування моделі

- `temperature=0` і `seed=42` зменшують варіативність класифікації.
- `max_tokens=440` обмежує відповідь і дає запас на коди відділів для 24 позицій. Таймаут запиту — 45 секунд.
- `num_ctx=4096` задається в обох Modelfile. Ввід обмежено 900 символами й 24 позиціями.
- Qwen отримує пронумеровані позиції й повертає коди відділів за JSON-схемою. Сервер перевіряє, що кожен номер отримав рівно один допустимий код, і групує початковий текст.

У блоці **Налаштування моделі** можна вибрати встановлену локальну модель, температуру, ліміт токенів, Top-p, seed, штрафи за повтори й режим міркування. Порожні необов’язкові поля залишають значення моделі. За замовчуванням використовується OpenAI-сумісний протокол. У режимі **Ollama API** доступні також Top-k і розмір контексту. Для моделей Ollama рівні Low, Medium та High через рідний API вмикають Thinking, якщо модель його підтримує.

## Бенчмарк у браузері

Вкладка **Бенчмарк** використовує налаштування моделі з верхнього блока. Вибери звичайні промпти з методички або списки покупок, зазнач рівні паралельності, кількість запитів, таймаут і назву запуску. Запити виконує локальний сервер, тому обмеження браузера на одночасні з’єднання з Ollama не впливає на кількість клієнтів.

- **TTFT p50, p95 і p99** — перцентилі часу до першого видимого токена, включно з очікуванням у черзі Ollama.
- **Ток/с на клієнта p50, p95 і p99** — перцентилі `(токени відповіді − 1) / час після першого токена`. Вищий перцентиль швидкості відповідає швидшим запитам.
- **Throughput** — сумарна кількість токенів усіх відповідей, поділена на тривалість рівня.
- Таблиця також показує кількість запитів і помилок, тривалість рівня, середню кількість токенів і факт міркування. Прогрів виконується окремим запитом і не враховується.

**Завантажити CSV** зберігає перші десять колонок у порядку методичного `bench.py` і додає в кінці TTFT p99 та ток/с p95 і p99. У режимі покупок бенчмарк використовує JSON-схему застосунку. Він вимірює потоки, а точність категорій перевіряється окремо скриптом `evaluate_shopping.py`.
