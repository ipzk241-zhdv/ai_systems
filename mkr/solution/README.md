# Ранковий дайджест Житомира, України і світу

Скрипт збирає заголовки, час і прямі посилання з вебсайтів. Локальна Qwen відбирає важливе й отримує завдання вибрати один заголовок, якщо ту саму подію висвітлили кілька разів. Скрипт підставляє оригінальні заголовки та адреси за ідентифікаторами публікацій.

## Запуск

Потрібні Python 3.10+, `curl` і запущений [Ollama](https://ollama.com/download). У Windows `curl` зазвичай уже встановлений. Виконай з кореня репозиторію.

```powershell
python -m pip install -r mkr2/solution/requirements.txt
ollama pull qwen3.5:9b
python mkr2/solution/digest.py
```

Файл `digest.md` з’явиться в поточній теці. Типове вікно — від 22:00 до 08:00 за Києвом. При запуску вночі вікно закінчується в момент запуску. Для ширшої вибірки запусти з `--hours 24`. `--collect-only` показує кількість новин та помилки за джерелами без звернення до Ollama.

## Telegram-бот

Коли Ollama запущено і Qwen3.5 9B завантажено, виконай у терміналі з кореня репозиторію:

```powershell
.\mkr2\solution\bot.ps1 start
```

Скрипт запускає бота у фоновому процесі Windows. Він використовує Python із `.venv` у корені проєкту, а за відсутності цього середовища бере `python.exe` із `PATH`. Токен зчитується з `TELEGRAM_BOT_TOKEN` у середовищі або з рядка `TELEGRAM_BOT_TOKEN=…` у локальному файлі `.env` поруч зі скриптом. Цей файл виключено з Git. Відкрий бота в Telegram і натисни **Start**. Бот доступний усім, хто відкриє з ним приватний чат.

```powershell
.\mkr2\solution\bot.ps1 status
.\mkr2\solution\bot.ps1 stop
```

`status` показує, чи працює бот. `stop` завершує його процеси. Для повторного запуску виконай `start`. Логи фонового процесу зберігаються в `mkr2/solution/.runtime/`.

Кнопки **За 4 години**, **За 8 годин** та **За 24 години** рахують період від моменту початку запиту. **З останньої перевірки** збирає новини з початку попереднього запиту в цьому чаті, на який бот успішно надіслав результат. Вікно обмежене 24 годинами. Перший запит цією кнопкою охоплює останні 24 години. Час перевірки зберігається окремо для кожного чату в локальній базі `.runtime/bot-<id>.sqlite3`.

Бот використовує ті самі джерела й ту саму модель, що й Markdown-версія. У відповідь надсилає автономний HTML-файл із розділами, часом публікації та прямими посиланнями. Його можна завантажити й відкрити в браузері. Блок ринків показує відсоткові зміни фондів SPY, QQQ і DIA за останню доступну сесію за даними [NineQuantAI](https://ninequantai.com/en/api#data-timeliness).

Відредагуй [importance.txt](importance.txt), щоб змінити, які події потрапляють у «Важливе», звичайну стрічку чи «Цікаве й смішне», а які пропускаються. Нові критерії діють із наступного запиту дайджесту.

Кнопка **Відключення** показує опубліковані інтервали для 12 підчерг на сьогодні та завтра, якщо є графік, і перші п’ять діючих записів по місту Житомиру. Для пошуку за вулицею напиши `Відключення: Київська`. Бот читає [таблицю графіка](https://www.ztoe.com.ua/unhooking-search.php) і JSON із публічних запитів [сторінки діючих відключень](https://ztoe-poweron.inneti.net/). Обидва запити працюють без Ollama. Графік показує заплановані інтервали, а записи API — стан, який опублікувало обленерго, з очікуваним часом відновлення.

Щоб поставити запитання, просто напиши в той самий чат. Можна надіслати окреме слово, як-от «канделябр», або написати «Що означає слово “манівці”?». Бот шукає такі слова в [СУМ-11 на Slovnyk.me](https://slovnyk.me/dict/sum/манівці). Інші запити, наприклад «Дай простий рецепт борщу», обробляє локальна Qwen3.5 9B. Для уточнень бот тримає в оперативній пам’яті до трьох попередніх обмінів у кожному з 32 останніх активних чатів. Після перезапуску ця історія очищується. Для свіжих новин скористайся кнопками.

## Джерела

Покриття залежить від доступності та глибини стрічок. Дайджест показує кількість знайдених публікацій і повідомляє про помилки джерел. Ateo Breaking використовує мітку `lastmod` з карти сайту як наближення до часу публікації. Публікації, які є лише в Telegram, у вибірку не потрапляють.
